# AI Research Assistant

A modular, citation-aware research assistant for turning source text into structured briefs. This repository is intentionally provider-neutral: plug in your preferred LLM and retrieval layer.

## Features
- Source ingestion and normalized evidence records
- Claim extraction with citation IDs
- Confidence-aware brief generation
- Deterministic demo mode for local development

## Quick start
```bash
python -m research_assistant.demo
```

> This is a research aid, not a substitute for expert review. Verify important claims against primary sources.
